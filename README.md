# ADSyncSolution Final

## Features
- Multi-school AD sync with Bromcom API
- Logging for all scripts
- Error handling with try/catch
- Write-back to Bromcom UDFs
- Email notifications with CSV report for starters
- EmployeeID injection for matched accounts only

## Action Scripts
- Starter_Staff.ps1
- Starter_Student.ps1
- Changes_Staff.ps1
- Changes_Student.ps1
- Leaver_Staff.ps1
- Leaver_Student.ps1

## Usage
Update XML configs with SMTP details and Bromcom credentials.
